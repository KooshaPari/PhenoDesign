PhenoDesign / Scene experiences

V3 · Source-backed working library

Scene first; preserve the design system

Status: proposed for the receiving repository.

Decision

Adopt scene treatment and authored state as a new capability inside PhenoDesign. Keep existing tokens, UI components, typography and ordinary product screens.

Rationale and alternatives

A theme swap or 3D hero alone misses the requested experience. A complete root restructure would create migration cost without proving value.

Consequences

Additive integration; require a real flagship consumer before extracting new packages.
