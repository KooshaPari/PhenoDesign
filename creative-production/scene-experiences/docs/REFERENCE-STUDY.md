# Reference study: principles, not imitation

Sources were revisited on 2026-09-15. We inspected available official page text/documentation;
we did **not** instrument the live Apple/Nike sites or claim their shader/video implementation.
A page's published narrative is not proof of scroll choreography. Capture those behaviors on an
approved local browsing worker before treating them as observed specifications.

## Agent reference-capture protocol

For a selected reference, capture a short permitted sequence: cold entry, first meaningful input,
midpoint, reverse, fast seek, mobile, reduced motion, task/CTA and failure/slow-media behavior.
Record viewport, date, exact URL and what actually occurred. A static preview does not answer
those questions. Keep study assets private where required and do not redistribute proprietary
media without rights. Retain concise original notes rather than mirroring whole sites.

In the treatment compare reference principles, not screenshots: what guides attention, what
changes state, how scale is established, how a transition stays coherent, and where utility
becomes available. Include one less theatrical alternative. Reference strength does not relieve
the agent of designing the user's actual subject.

## Discovery shelf

Dribbble, Awwwards, FWA and Codrops can locate interesting directions. Treat an individual shot,
award or tutorial as a lead, not production certification. Prefer the original creator's case study,
live surface and source/docs when available. Separately note unavailable or paywalled resources.
The supplied catalog intentionally distinguishes observed sources from discovery-only entries.
